    Publicación automática (GitHub)

    Con esto, al tocar Aprobar la cuenta se activa sola, sin subir archivos. Se configura una vez en cada celular o computadora de administrador.

    ¿Cómo saco el token? (lo hace Samuel una vez)
    1. En GitHub abre github.com/settings/personal-access-tokens/new.
    2. Token name: “Cachanilla administración”. Expiration: 1 año.
    3. Repository access: Only select repositories → mipaginawebcachanilla-.
    4. Permissions → Repository → Contents: Read and write. Nada más.
    5. Generate token, cópialo y pégalo aquí. Para que otro administrador publique desde su celular, pégale el mismo token en su equipo.
    Si pierdes un celular: en GitHub → Settings → Developer settings → Fine-grained tokens, bórralo y crea otro.

    Compartir los datos entre administradores

    Para que todos los administradores vean los mismos pedidos, se guardan en un repositorio privado de GitHub (nadie más lo ve).

    1. En GitHub crea un repositorio nuevo llamado cachanilla-datos y márcalo Private.
    2. Edita tu token (Settings → Developer settings → Fine-grained tokens) y añade ese repositorio con Contents: Read and write.
    3. Escribe aquí el repositorio y toca Conectar.
